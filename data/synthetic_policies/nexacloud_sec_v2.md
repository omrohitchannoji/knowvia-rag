# NexaCloud Information Security Policy v2.0

## 1. Purpose & Scope
This policy defines the security standards, compliance requirements, and access controls for all internal systems at NexaCloud.

## 2. Updated User Authentication Requirements
All corporate accounts must enforce multi-factor authentication (MFA) and strong password complexity.

## 3. Production System Access
Production database access is restricted strictly to authorized DevOps and Database Administrator personnel.
